Convoy · UI redesign concepts

A warm, light, editorial system instead of the dark-navy-and-glow look: paper-white surfaces, ink typography with a serif wordmark, hairline borders, soft shadows — and exactly one accent, forest green, used for you, the route, and primary actions. Member identities get muted earth tones. No gradients, no neon, no blue. This is the visual language of trusted travel products (Airbnb, Polarsteps, AllTrails), not a tech demo.
